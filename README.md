# Marble Minds Club

I want to create a new website for a computer science club for older people.

They currently have an old site http://computerclubhhw.nl/ 

They have a couple of categories (Nieuws, Bestuur, Lidmaatschap, Cursussen, Technische Dienst) which need to be available as menu items.

On the frontpage they have a slider where they can add images.

The "Bestuur" and "Cursussen" pages are grids showing pictures with a small subtitle often linking towards a detail page.

Bestuur contains the board members and Cursussen the available courses.

The site has to be quirky and refreshing but AAA for accessibility.
So acessibility first.

We need to be able to support zooming in and out without the fonts looking odd.

We need to think about colour blindness and keyboard navigation.

They really like the current theme we have which uses Purple, Beige and marble like textures.
